# 카풀 기능 설계 스펙

**날짜**: 2026-05-15  
**상태**: 승인됨

---

## 1. 개요

체육대회 참가자들이 카풀을 등록하고 탑승 신청을 할 수 있는 기능.  
운전자가 차량을 등록하면 다른 참가자들이 탑승 신청하거나, 운전자가 직접 초대할 수 있다.  
귀가 카풀을 위해 운전자가 선택적으로 목적지를 입력할 수 있다.

## 4. 데이터 모델 (Supabase)

### `carpool_cars` 테이블

| 컬럼 | 타입 | 설명 |
|---|---|---|
| `id` | uuid (PK) | |
| `driver_id` | uuid (FK → users.id) | 운전자 |
| `car_number` | text | 차 번호 (예: 가나1234) |
| `contact` | text | 연락처 |
| `capacity` | int (2~4) | 탑승 가능 인원 (운전자 제외) |
| `destination` | text (nullable) | 귀가 목적지 (선택사항, 미입력 시 체육대회장행으로 표시) |
| `created_at` | timestamptz | |

### `carpool_passengers` 테이블

| 컬럼 | 타입 | 설명 |
|---|---|---|
| `id` | uuid (PK) | |
| `car_id` | uuid (FK → carpool_cars.id) | |
| `user_id` | uuid (FK → users.id) | 탑승자 |
| `created_at` | timestamptz | |

**제약조건**:
- `carpool_passengers.user_id` unique — 한 사람이 여러 차에 탑승 불가
- `carpool_cars.driver_id` unique — 한 사람이 여러 차 등록 불가
- 탑승자 수는 `capacity`를 초과할 수 없음 (API에서 검증)
- `carpool_passengers.car_id`는 `carpool_cars.id`에 `ON DELETE CASCADE` — 차량 삭제 시 탑승자 레코드도 자동 삭제

## 5. UI 구조

### 5-1. 메인 페이지 (`/carpool`)

**2단 레이아웃**:
- **왼쪽 (flex 1.6)**: 차량 카드 그리드
  - 각 카드: 운전자 이름, 차 번호, 연락처, 좌석 현황 (동그라미로 시각화), 목적지 (있을 경우 🏠 아이콘과 함께 표시)
  - 빈 슬롯 카드: "+ 차량 등록하기" (클릭 시 등록 모달)
  - 우상단: "내 차 등록" 버튼 (본인이 아직 등록 안 한 경우에만 표시)
  - 차량 카드 클릭 → 상세 모달 열림
- **오른쪽 (flex 1, 노란 배경)**: 미배정 인원 명단
  - 카풀에 등록되지 않은 전체 가입자 목록
  - 이름 + 마을 표시

**비로그인 사용자**: 차량 목록과 미배정 명단은 볼 수 있으나, 탑승/등록 버튼은 로그인 유도

### 5-2. 차량 상세 모달

**공통**: 운전자 이름, 차 번호, 연락처, 목적지 (있을 경우), 탑승자 목록 (운전자 + 탑승자 구분)

**일반 사용자 시점**:
- 탑승자 목록 보기
- "🙋 나도 탑승하기" 버튼 (빈 자리가 있고, 본인이 아직 미배정인 경우에만 활성화)
- 이미 탑승 중인 경우: "🚪 탑승 취소" 버튼

**운전자 시점 (본인 차)**:
- 수정 버튼 (차 번호, 연락처, 정원 수정)
- 삭제 버튼 (탑승자 전원 미배정으로 복귀)
- 탑승자 옆 "✕ 내보내기" 버튼
- "👋 미배정 명단에서 초대하기" 버튼 → 미배정 명단 목록 표시 → 이름 클릭 시 자동 배정

### 5-3. 차량 등록 모달

- 차 번호 (텍스트 입력)
- 연락처 (텍스트 입력)
- 탑승 가능 인원 (2 / 3 / 4 선택)
- 목적지 (텍스트 입력, 선택사항 — 귀가 카풀용. 미입력 시 카드에 목적지 표시 안 함)
- 등록 버튼

운전자 이름은 세션에서 자동 사용.

## 6. API 라우트

| 메서드 | 경로 | 설명 |
|---|---|---|
| `GET` | `/api/carpool/cars` | 전체 차량 목록 (탑승자 포함) |
| `POST` | `/api/carpool/cars` | 차량 등록 (인증 필요) |
| `PATCH` | `/api/carpool/cars/[id]` | 차량 정보 수정 (운전자 본인만) |
| `DELETE` | `/api/carpool/cars/[id]` | 차량 삭제 (운전자 본인만) |
| `POST` | `/api/carpool/passengers` | 탑승 신청 또는 초대 (인증 필요) |
| `DELETE` | `/api/carpool/passengers/[id]` | 탑승 취소 또는 내보내기 |
| `GET` | `/api/carpool/unassigned` | 미배정 인원 목록 |

## 7. 권한 규칙

| 액션 | 조건 |
|---|---|
| 차량 등록 | 로그인 + 본인이 운전자/탑승자로 미등록 상태 |
| 차량 수정/삭제 | 해당 차량의 운전자 본인 |
| 탑승 신청 | 로그인 + 미배정 상태 + 해당 차 빈 자리 있음 |
| 탑승 취소 | 본인 탑승 건 |
| 초대 | 해당 차의 운전자 본인 + 초대 대상이 미배정 상태 + 빈 자리 있음 |
| 내보내기 | 해당 차의 운전자 본인 |
